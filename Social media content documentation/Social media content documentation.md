# Social media content documentation 

This document is a step by step on how to use the backtrack feature on OBS. 

## Step by step

- Open OBS and open settings. 
- Go onto output and change output mode to 'advanced' 
- select replay buffer and enable it 
- set it to 1200s (10 minutes)
- go onto recordings and select the format to be hybrid mp4 and the encoder to be this :
![alt text](https://raw.githubusercontent.com/kdogz9/Images-for-technical-art/refs/heads/main/Screenshot%202026-03-10%20154939.png)
- apply these settings 
- go to hot keys and search in the filter bar 'replay' and the bindings as showed below 
![alt text](https://raw.githubusercontent.com/kdogz9/Images-for-technical-art/refs/heads/main/Screenshot%202026-03-10%20155112.png)
- click apply and close this window
- add a display capture in the sources 
- when ready press the key binded to start replay buffer and this will record the last ten minutes constantly 
- if a clip needs to be saved you need to press the key for save replay and this will save that specific clip
